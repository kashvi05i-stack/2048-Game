# 2048 Game using Python

## Overview

This project is a graphical implementation of the popular 2048 puzzle game developed using Python and the Tkinter library. The game allows users to combine numbered tiles by moving them in different directions to reach the 2048 tile while tracking scores and high scores.
The project demonstrates the implementation of GUI development, game logic, object-oriented programming, and event handling in Python.

## Gameplay Rules
- The game starts with two numbered tiles.
- Use arrow keys to move all tiles in one direction.
- Tiles with the same number merge when they collide.
- A new tile appears after every move.
- The objective is to create the **2048** tile.
- The game ends when no moves are possible.

---

## Functionalities

### 1. Tile Generation
Random tiles (2 or 4) are generated after each move.

### 2. Tile Merging
Tiles with equal values merge automatically during movement.

### 3. Score Tracking
The score increases whenever tiles merge.

### 4. High Score System
Tracks the highest score achieved during gameplay.

### 5. Win Detection
Displays:
```text
YOU WON!
```
when the player reaches the 2048 tile.

### 6. Game Over Detection
Displays:
```text
GAME OVER
```
when no further moves are possible.
